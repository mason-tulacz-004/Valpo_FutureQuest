This project is a 2D pixelated video game themed around Valparaiso University and made in the GoDot Engine. 
Players tour the campus searching for torches and completing quizzes which will point them towards a career archetype based
on the official U.S. Department of Labor O*Net Career Exploration Tool. While exploring, players will also get a virtual tour of
Valparaiso University, and are able to interact with the environment around them to find secrets. This initiative partnered with
the university's marketing team as we hope this project can serve prospective students in a meaningful and engaging way.
This project served as my senior capstone and is currently live on the Valparaiso University Website at 
https://www.valpo.edu/valpo-futurequest/
